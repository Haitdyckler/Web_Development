# Web Development Projects

A collection of front-end mock projects built with vanilla HTML/CSS/JS and React. Each project focuses on responsive design and clean UI, recreating real-world brand interfaces as practice exercises.

---

## Projects

### Cadence — `cadenceHtml/`
A hydration and sports nutrition brand landing page. Built with vanilla HTML, CSS, and JavaScript, featuring a transparent scroll-triggered navbar, Shop dropdown, and a responsive header/footer layout.

**Stack:** HTML · CSS · JavaScript

---

### Two Leaves Tea — `twoleavestea-html/` & `twoleavestea-react/`
A tea brand website implemented twice — once in vanilla HTML/CSS/JS and once in React — to compare approaches and explore component-based architecture.

**Stack:** HTML · CSS · JavaScript · React

![preview](https://raw.githubusercontent.com/Haitdyckler/Web_Development/previews/twoleavestea_2.png)

---

### Locavore — `locavore_Demo_React/`
A restaurant or local food brand demo page built in React, showcasing component structure and layout design.

**Stack:** React

---

### Zildjian — `zildjian_react/`
A mock site for the iconic cymbal and drumstick brand, built in React.

**Stack:** React

### Interview Demo — `Interview_Demo_HTML/`
A front-end demo built in vanilla HTML/CSS/JS, created as an interview exercise.

### Web Test — `web_test/`
A sandbox folder for experimenting with layouts and UI ideas.

**Stack:** HTML · CSS · JavaScript

---

## Tech & Approach

- **Vanilla HTML/CSS/JS** for lightweight, dependency-free builds
- **React** for component-driven, reusable UI architecture
- **Responsive design** throughout — layouts adapt cleanly across screen sizes
- **Clean UI** with attention to typography, spacing, and visual hierarchy

---

## Getting Started

**Vanilla HTML projects** — open the relevant `index.html` directly in a browser, no build step needed.

**React projects** — from the project folder:

```bash
npm install
npm start
```
